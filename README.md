# SiiD Quest概要
- 受講生に仕事を発注します
- 半分仕事、半分学習
- 普段の成績や授業態度がいい人のみ
- 金額はやすいのでそこは期待しないで
- 目的：あくまで転職やほかでの案件獲得に近づくためのステップ
- 仕事なのでガチ。ちゃんと取り組める人。納品締切も設けます
- コードレビュー、GitHubでのソロ開発、チーム開発などアリ
- 履歴書に業務経験として書いてOK（4,000pt以上推奨）

# 期待値
- "コミュ力"
- 成果物
- スケジュール（フィードバックあり）

# ルール
- Step 23、および「SiiD Quest」のまで完了していること
- 転職がゴールの人が優先
- 質問は”仮説思考”で行う
- 生成AIの利用はOK。ただしちゃんと理解していること
